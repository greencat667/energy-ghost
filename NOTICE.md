# Third-party code and data

- `energy_ghost/src/display/` and `energy_ghost/src/power/` - hardware driver code adapted from Waveshare's official example code for the ESP32-S3-ePaper-1.54 board (https://www.waveshare.com/wiki/ESP32-S3-ePaper-1.54). Waveshare's examples carry no explicit licence file in the copy this was taken from; they are published for use with their hardware. If you are a Waveshare representative and would like this handled differently, please open an issue.
- `energy_ghost/ghost_art.h` - six ghost illustrations generated locally with Draw Things (Stable Diffusion), thresholded to 1-bit bitmaps. Generated by the project author; no third-party artwork is included.
- Data: GB carbon intensity from the Carbon Intensity API (https://carbonintensity.org.uk), a National Energy System Operator (NESO, formerly National Grid ESO) service, data licensed CC BY 4.0. Location lookup via ip-api.com (see the README for its terms). No data from either service is stored in this repo.
- Libraries used at build time (not vendored): Adafruit GFX Library (BSD licence) and the Arduino-ESP32 core (LGPL 2.1).
